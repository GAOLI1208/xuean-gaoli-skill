# xuean-gaoli：把真实物理题变成可讲、可查的学案

`xuean-gaoli` 是一个面向初高中物理老师的教学学案生成技能。它不只做“排版”：从找题、核对原题和图片，到把来源答案逐空对应，再到生成题目版/来源答案版 PDF，都尽量留下可回查的记录。

代码和完整技能在仓库根目录的 **`xuean-gaoli-skill.zip`**；本 README 是使用说明，不重复放源码。

## 它解决什么

老师备课时常遇到这些麻烦：

- 搜到一道题，但题图、选项或小问不完整；
- 有答案，但答案和空位对不上，或者只是“见解析”；
- 题面、答案、图片来源散在几个地方，过几天无法回查；
- 想先给学生题目版，答案另存，却容易把答案一起印出来；
- 题目能用，但排版、图问位置、字号需要逐页检查。

这个技能把上述步骤串成一条可检查的流程：**找候选 → 核原题 → 提取图文 → 映射来源答案 → 生成题目版/答案版 → 审核、审计、逐页目视、交付**。

## 老师可以这样用

不需要记命令，先像平时说话一样提需求：

> 找一道初中声音的真实题，要有两种声音的示波器波形图，至少两个分别作答的空，考音调高低和响度；要完整题图和来源答案，先给我候选。

> 用这个页面/这份 PDF 提取第 X 题，保留原题图和小问；答案按空逐项对应，先做题目版，答案另存。

> 把已选的这道题做成来源答案版，检查每一页的图、空位、单位和答案位置。

技能会把自然语言需求整理成条件，按条件搜候选、逐条写证据，而不是只凭“看起来像”直接选中。多空题要求逐空覆盖，并有来源答案、答案占位、题图缺失等检查和阻断机制；这些机制不能保证识别所有情况，最终仍需回源和人工确认。

完整命令和字段说明见 zip 内的 `SKILL.md` 与 `references/`；日常使用可以从上面的自然语言开始。

## 已经实现的通用能力

- **按条件找候选**：把学段、知识点、题型、题图、答案要求写成硬条件；候选要有原文片段和覆盖范围，不靠摘要猜题。
- **提取完整题面**：HTML/PDF/扫描页都能进入统一记录；题干、选项、小问、题图、答案图分块保存，懒加载图片和相对地址会解析。
- **来源记录**：保存原页/原文件、页面或选择器、hash、抓取信息；模型摘录不能冒充原件。
- **答案逐空对应**：支持多空、多个小问和答案图；一个父标签不能糊弄多个空位，答案“见解析/略”会阻断。
- **两种交付**：题目版不显示答案；来源答案版按空显示答案。老师只要题目版时，有 requested_mode/display_answers 检查，默认不印答案；但交付模式仍需核对，不能保证所有情况自动识别。
- **检查链**：导入、准入校验、审核、构建、PDF 审计、逐页目视、交付各有记录；换 PDF 或只看部分页不会冒充已验收。

## 一个真实使用结果

第 7 轮独立验收中，有一道**真实初中声音示波器波形题**：

- 原题有两种声音的波形（图1 A/B，图2 甲/乙），题干有 3 个分别作答的空；
- 题图和来源答案完整，答案按空对应为 `A / A / 甲`；
- 模型辅助把同一段的三个空结构化为 (1)–(3)，并完成逐空映射；
- 最终生成 1 页 A4 学案，题图、三个作答点和答案位置经独立验收核对；
- 成品 PDF 的 sha256 为 `34ca24781cbc41e8e7d37a171139a8de7a2ab2f26e27f32b5e8e0941be2e22b5`。

这不是“全自动做完整套卷”，而是一个可复核的真实样例：**题图在、空位在、来源答案能逐项对上，模型辅助的位置也明确标出**。需要同时说明：该 R1 的来源年份未被原页直接证实，成品曾把学年推断成 2023；文字/图注也发生过重排。图、空和答案的对应已核对，但日期与文字保真仍必须回源复核。

第 7 轮六项陌生需求中，B1/B3/B5/B6 的题面完整，B1/B5/B6 按正确模式交付了来源答案版；B4 的漏图被后续校验拦截，B2 超预算后按失败记录。后续两项复测里，R1 声音题通过；R2 高中电磁感应题在 6 次搜索/4 个详细打开内没有找到同时满足“方向 + 大小 + 两问 + 来源答案”的候选，按失败保留。**没有把失败项回填成成功，也没有声称复测全自动完成。**

## 示例安装

从仓库根目录下载 `xuean-gaoli-skill.zip` 后：

```sh
mkdir -p xuean-gaoli
unzip xuean-gaoli-skill.zip -d xuean-gaoli
cd xuean-gaoli
chmod +x install.sh uninstall.sh bin/xuean
./install.sh /path/to/your-project
```

安装后从项目工作区根启动 DSH，新会话确认：

```text
.dsh/skills/xuean-gaoli/SKILL.md
```

只在本包目录运行：

```sh
chmod +x install.sh uninstall.sh bin/xuean
PYTHON=/path/to/python3.12 ./install.sh ./
./bin/xuean doctor
```

安装器在项目内创建隔离 `.venv`，不修改用户级目录；不需要把 Python 解释器或第三方二进制打进仓库。卸载用 `./uninstall.sh /path/to/your-project`。

## 测试状态与真实边界

- 安装、`--help`、`doctor` 和自造最小流程已在隔离项目验证；自造示例明确不是真实试题。
- **Python 版本门槛是 >=3.10, <3.14，但当前仅实际验证 3.12**；3.10/3.11/3.13 是预期范围，未逐版验证。
- 这个技能仍是实验候选，主要验证初高中物理；不是任意网站、任意版式的全自动系统。
- 找题、OCR、图文关系、年份/地区/来源核验可能需要模型辅助；模型结构化、选框或改字会留下辅助记录，不能包装成程序直提。
- 搜索预算是流程约束，不是硬隔离；直接调用工具可能绕过 CLI，实际调用轨迹仍要保存。
- 年份、地区、考试名称、材料性质必须回源核实；来源是作业/题库时，应按实际材料性质标注，不能仅凭页面标题写成“真实考试题”。历史曾有误标，当前有相关检查但不能保证完全识别。
- macOS 的 Typst 中文字体已按当前环境验证；扫描页/OCR 的实际识别在本次发布验证中未运行，Vision OCR 路径只检查过存在，不能视为已验证；Linux/Windows 和非 macOS 字体环境未充分验证。
- 本仓库只带自造示例，不带真实试卷、个人数据、账号配置或第三方题图；真实材料的使用范围和版权由使用者核实。
